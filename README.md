# 项目名称：blog-system

## 项目简介
这是一个基于 Spring Boot 的博客系统，实现了文章管理、标签管理等功能。

## 技术栈
- 后端：Java + Spring Boot + MyBatis
- 数据库：MySQL
- 前端：HTML + Thymeleaf

## 快速开始
1. 克隆项目：`git clone https://github.com/renlianqi/blog-system.git`
2. 配置数据库连接
3. 启动项目：运行 `BlogSystemApplication.java`

## 功能说明
- 文章的增删改查
- 标签分类管理
- 文章详情页展示
